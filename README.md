
# Landing Page — Negocio de Barrio

> Proyecto del **Sprint 01** ([HU-S01-02](https://github.com/Fundacioncepav/impulsoDigital/blob/main/sprint-01/HU-S01-02-landing-negocio.md)) para el programa **Impulso Digital — Fundación CEPAV**.

---

## 📌 Sobre el proyecto
Este proyecto consiste en el diseño y desarrollo de una landing page real, accesible y responsive para un negocio local de barrio, enfocada en resolver sus necesidades de visibilidad, mostrar sus productos/servicios y facilitar el contacto directo por WhatsApp.

## 👥 Para quién es
- **Dueño del negocio:** Para atraer más clientes y centralizar información sobre horarios, ubicación y catálogo.
- **Clientes:** Para consultar rápidamente precios, productos y hacer pedidos directos.
